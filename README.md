# 国産パソコン年表

日本のパソコンの発売時期を、メーカー別・系列別の一枚の年表として眺めるためのビューアです。

## 概要

- 縦軸は年月です。**1か月を完全に等間隔**で配置します。年ごとの粗密がないため、発売間隔をそのまま長さとして読み取れます。
- 横軸はメーカーです。並び順は年表データ `timeline.md` に書かれた順そのままです。
- 同じメーカーの中は**系列ごとにレーン（縦の列）**に分かれ、同じ系列の機種どうしが発売順に線で結ばれます。
- ある系列が別の機種から派生した場合は、派生元の機種から派生先の系列の初代へ**破線の矢印**が引かれます。
- 左端の年月軸には昭和／平成の帯を表示し、1989-01-08 の平成開始位置に境界線を描きます。

特徴:

- 年表データは**テキストファイル1枚**（`timeline.md`）です。これを読み込んで画面を組み立てます。
- **外部ライブラリ・外部CDN・外部フォントを一切使いません。** 素の HTML / CSS / JavaScript のみの静的サイトです。
- 描画は SVG なので、拡大しても文字や線が荒れません。
- 前後の機種や経過月数は年表データには書きません。発売年月から自動で計算します。
- ブラウザにインストールして、オフラインでも利用できます。

## ローカルでの起動方法

年表データを `fetch()` で読み込むため、**`index.html` をファイルとして直接開いても動きません**（`file://` ではブラウザがローカルファイルの取得を拒否します）。簡易 HTTP サーバ経由で開いてください。

```bash
cd OldPCHistory
python3 -m http.server 8000
```

ブラウザで <http://localhost:8000/> を開きます。

Node.js を使う場合:

```bash
npx --yes http-server -p 8000 .
```

## 使い方

| 操作 | 内容 |
| --- | --- |
| 機種ボックスをクリック（または `Enter` / `Space`） | 詳細を開く。メーカー・機種名・発売年月・系列・系列の分岐・前後の機種と経過月数を表示します |
| 閉じるボタン / 背景クリック / `Esc` | 詳細を閉じる |
| メーカー名のボタン | そのメーカーの表示の ON / OFF。OFF にすると列ごと消え、レイアウトが詰まります |
| 「8bit」「16/32bit」のボタン | ビット数での絞り込みの ON / OFF。OFF にした分類だけに属する系列のレーンが畳まれます。分類のない系列は常に表示されます |
| 検索ボックス | 機種名のインクリメンタル検索。ヒットは強調、それ以外は減光し、件数を表示します。隣の `×` でクリアします |
| 年の選択 | 選んだ年の1月へスクロールします |
| `+` / `-` / `等倍` ボタン | 拡大 / 縮小 / 100%に戻す（45%〜300%） |
| `Ctrl` + マウスホイール | 拡大 / 縮小 |

キーボード操作:

| キー | 動作 |
| --- | --- |
| `+` | 拡大 |
| `-` | 縮小 |
| `0` | 等倍に戻す |
| `/` | 検索ボックスへフォーカス |
| `Enter`（検索ボックス内） | 最初のヒットへスクロール |

上端のメーカー見出しは縦スクロールに、左端の年月軸は横スクロールに追従します。

## `timeline.md` のデータ形式

行指向のプレーンテキストです。機種を1件追加するには、該当するメーカーの節に1行足すだけです。

```text
# タイトル（自由に書けます。読み飛ばされます）

## メーカー名
color: #RRGGBB
lanes: 系列名, 系列名, 系列名
branch: 子系列名 < 親機種名

YYYY-MM | 機種名 | 系列名
YYYY-MM | 機種名 | 系列名
```

| 記法 | 必須 | 意味 |
| --- | --- | --- |
| `## メーカー名` | 必須 | メーカーの区切り。書いた順に左から並びます |
| `color: #RRGGBB` | 任意 | そのメーカーの色。省略すると灰色になります |
| `lanes: A, B, C` | 任意 | 系列（縦のレーン）を左から並べる順。カンマ区切り。省略すると機種行に現れた順になります |
| `branch: 子系列名 < 親機種名` | 任意・複数可 | ある系列が別の機種から派生したことを表します。年表上では親機種から子系列の初代へ破線の矢印が引かれます。区切りは `<` です（機種名にスラッシュを含むことがあるため） |
| `8bit: A, B` / `16bit: A, B` | 任意・複数可 | 系列をビット数で分類します。カンマ区切り。分類した系列は画面上部の「8bit」「16/32bit」ボタンで絞り込めます。同じ系列を両方に書けば両対応機として扱われ、どちらかの分類が表示中なら残ります。どちらにも書かれていない系列は絞り込みの影響を受けず、常に表示されます |
| `YYYY-MM \| 機種名 \| 系列名` | — | 機種1件。`\|` 区切りで、発売年月・機種名・所属する系列を書きます |

機種行の詳細:

- 同じ系列名を持つ機種どうしが、同じレーンにまとめられ、発売順に線で結ばれます。行を書く順番は問いません（発売年月で自動的に並べ替えます）。
- 経過月数や前後関係は書きません。発売年月から自動計算されます。
- 1行に複数の機種をまとめて書いても構いません（例: `S1/10 / S1/20`）。その場合、年表上ではひとつの箱として扱われます。機種ごとに分けたい場合は行を分けてください。
- 年表の表示範囲の外の年月は、描画対象から外れます。

空行、`#` で始まる見出し行、`<!--` で始まる行、` ``` ` や `~~~` で囲まれた範囲は読み飛ばします。解釈できない行も読み飛ばし、ブラウザのコンソールに警告を出したうえで読み込みを続けます。

### 記入例

`lanes:` でレーンの並び順を決め、`branch:` で派生関係を示した例です。

```text
## HITACHI
color: #4B7BEC
lanes: BASIC MASTER, S1
branch: S1 < BASIC MASTER Level 3 Mark 5 MB-6892

1978-09 | BASIC MASTER MB-6880 | BASIC MASTER
1983-05 | BASIC MASTER Level 3 Mark 5 MB-6892 | BASIC MASTER
1984-05 | S1/10 / S1/20 | S1
1984-12 | S1/30 / S1/40 | S1
```

`BASIC MASTER` と `S1` の2レーンがこの順に並び、`BASIC MASTER Level 3 Mark 5 MB-6892` から `S1` 系列の初代 `S1/10 / S1/20` へ破線の矢印が引かれます。
